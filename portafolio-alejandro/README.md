# Portafolio · Alejandro Guerra Gómez

Sitio estático (HTML + CSS + JS), sin dependencias ni paso de compilación.

## Estructura
- `index.html` – Inicio
- `sobre-mi.html` – Sobre mí
- `portafolio.html` – Portafolio + cartas de recomendación
- `cambio-social.html`, `comunicacion-estrategica.html`, `otras-actividades.html` – Subpáginas de proyectos
- `css/styles.css` – Todos los estilos (colores en `:root`)
- `js/main.js` – Animaciones de entrada
- `assets/img/` – Imágenes optimizadas (WebP)

## Publicar en GitHub Pages
1. Crea un repositorio (por ejemplo `portafolio`) y sube el contenido de esta carpeta a la raíz.
2. En GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`**.
3. En 1–2 minutos quedará en `https://TU-USUARIO.github.io/portafolio/`.
   (Si el repo se llama `TU-USUARIO.github.io`, quedará en la raíz.)
4. Dominio propio: Settings → Pages → *Custom domain* y apunta el DNS a GitHub.
